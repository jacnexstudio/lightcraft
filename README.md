# Lightnex

Biblioteca de fotos y revelado RAW. Parte de la suite Jacnex.

Se instala y actualiza desde [Jacnex Studio](https://github.com/jacnexstudio/jacnex-studio).
Descargas: [versiones publicadas](https://github.com/jacnexstudio/lightcraft/releases).

Basado en [LightCraft](https://github.com/storytold/lightcraft) (MIT o Apache-2.0), con la marca Jacnex.
Cómo se compila: [jacnex-build](https://github.com/jacnexstudio/jacnex-build).
Jacnex no está afiliado ni respaldado por el ArtCraft Team.
